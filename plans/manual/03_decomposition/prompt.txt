Sub-module gợi ý:
- **PFORM:** (a) Nhận diện — Name, SKU, Price, Compare at, Brand; (b) Phân loại — Department, Subcategory; (c) Gallery ảnh; (d) Status, New, In stock, Condition, Availability, Rating, Stock count; (e) OEM / Alternate part numbers, Compatible model; (f) Mô tả; Tạo vs Sửa.

### 2. Mô tả chức năng

Với mỗi Module/Sub-module trong scope, cung cấp:
- Mã + tên module
- Mô tả chức năng (1–2 câu) bám theo doc
- Route FE / endpoint BE chính
- Thành phần UI chính (nút, hộp thoại, toast, bộ đếm…)
- Đánh dấu `[GIẢ LẬP]` nếu là màn dữ liệu mẫu

### 3. Sơ đồ phụ thuộc (Dependencies)

Chỉ ra phụ thuộc và dữ liệu tương tác giữa các Module, tối thiểu gồm:

[Gợi ý PARSCA:
- ROLE → LOGIN: role quyết định guard `/vendor/*`, `/admin/*`
- LOGIN / SESS → mọi module: cookie phiên, refresh, 401
- PFORM / CSV → SCOPE: `createdBy` = tài khoản tạo
- IMG → PFORM: ảnh upload là input của Gallery
- PFORM / CSV / PSTAT → WEB: Active hiện ngay, Draft / Archived / Xoá → 404 trên storefront
- CSV → SET / bộ lọc website: brand / xe mới (Q-V5)
- PSTAT → IMG: xoá sản phẩm dọn ảnh (trừ ảnh dùng chung)
- API (05) là lớp kiểm tra chéo cho ROLE, SCOPE, PFORM, CSV]

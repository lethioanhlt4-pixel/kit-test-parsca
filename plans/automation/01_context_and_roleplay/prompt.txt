## Nguyên tắc bắt buộc

1. **Page Object Model:** locator chỉ trong `pages/`; spec không có `page.locator` inline
2. **Smart Waits:** KHÔNG dùng `page.waitForTimeout`; dùng `expect().toBeVisible()`, `toHaveURL()`, `waitForResponse()`
3. **DOM Recon First:** TUYỆT ĐỐI không đoán locator — inspect DOM thật theo `.agent/rules/selectors.md`
4. **Unique Test Data:** `AUTO-<MOD>-<timestamp>`, `auto.<mod>.<tc>.<ts>@auto.test` theo `.agent/rules/test-data.md`
5. **Clean Code:** không `console.log`, không code comment-out, không import thừa
6. **Bảo mật:** không log / commit credentials, cookie, token, `.env`, `.auth/`

## Bối cảnh hệ thống (Context)

- FE là SPA; vendor portal ở `/vendor/*` (Dashboard, Product Catalog, Orders, Review, Payouts; Profile và Settings ở thanh trên).
- Phiên dùng cookie; refresh token xoay vòng (dùng lại → "Invalid session"); login quá 5 lần/phút → 429.
- Phạm vi dữ liệu theo `createdBy`: sản phẩm người khác → API 404 "Product not found"; API quản trị → 403; trường lạ → 400.
- Màn **giả lập** (Dashboard, Orders, Order detail, Reviews, Payouts, Settings, Profile trừ avatar): chỉ assert hiển thị + không có request API cấm.
- Vai test (biến `.env`): VENDOR1 (chính), VENDOR2 (đối chứng), ADMIN, USER, ROLE_TEST (đổi role / reset mật khẩu).

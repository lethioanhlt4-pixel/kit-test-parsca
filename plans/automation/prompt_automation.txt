=== NGUYÊN TẮC BẮT BUỘC ===

1. Pre-flight: Chưa xác nhận prefix /v1 hoặc thiếu biến .env → DỪNG và hỏi tôi, không đoán.
2. DOM Recon First: Mở browser (MCP) theo thứ tự navigate → resize(1920x1080) → wait_for → snapshot. TUYỆT ĐỐI không đoán selector. Ưu tiên getByRole > getByLabel > getByPlaceholder > getByTestId > getByText > id/name > CSS > XPath (theo .agent/rules/selectors.md).
3. Page Object Model: Locator chỉ trong pages/; spec không có page.locator inline.
4. Smart Waits: KHÔNG dùng page.waitForTimeout. Dùng expect().toBeVisible(), toHaveURL(), waitForResponse().
5. Test Data: SKU AUTO-<MOD>-<timestamp>, email auto.<mod>.<tc>.<ts>@auto.test qua utils/dataFactory.ts. Setup bằng API, teardown xoá sản phẩm AUTO-* do chính vendor tạo. Không xoá dữ liệu không có tiền tố AUTO-.
6. Mapping nhãn: @CodeHienTai chưa có câu trả lời PO → test.fixme() + annotation Q-Vx; @GiaLap → chỉ assert hiển thị + không có request API cấm; @NeedDevSupport → test.skip có điều kiện.
7. Self-fix Loop: Chạy headed, FAIL thì đọc log/trace, sửa, chạy lại đến khi PASS 2 lần liên tiếp; sau đó chạy headless.
8. Bảo mật: Không log/in credentials, cookie, token; không commit .env, .auth/, trace.
9. Clean Code: Sau khi PASS, xoá console.log, code comment-out, locator/import thừa.

=== QUY TRÌNH THỰC HIỆN (AI tự chạy toàn bộ) ===

Tự động thực hiện tuần tự 6 bước sau mà KHÔNG cần hỏi tôi (trừ khi thiếu pre-flight hoặc gặp business rule mâu thuẫn với doc):

1. Tiếp nhận context, kiểm tra pre-flight, xác nhận scope TC
2. Mở browser, điều hướng {FE_URL}, inspect DOM, thu thập locators (bảng Page / Element / Locator / Fallback / Verified)
3. Thiết kế POM: pages/vendor/*, api/* với locators từ Bước 2
4. Sinh Test Data: utils/dataFactory.ts + danh sách file test cần có (ảnh, CSV)
5. Sinh spec: mỗi test có TC ID ở đầu title + tag; chạy, self-fix đến PASS 2 lần
6. Cleanup + review theo checklist /review-script, báo cáo PASS / FAIL / SKIP (kèm lý do)

Bắt đầu ngay. Xác nhận ngắn gọn kết quả pre-flight rồi tiến hành Bước 2 (mở browser inspect DOM).
